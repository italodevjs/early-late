# Security

This application has no accounts, server database, analytics or uploaded audio. Charts and replay evidence remain on your device unless you share exported files. Chart imports are size-bounded JSON, validated for finite timing, lane bounds, grid positions and overlap. Imported titles are rendered as text.

The public demo should be served over HTTPS with no sensitive data on its origin. Browser extensions, shared devices and other scripts on the same origin can access local storage. Local results and JSON exports are editable and are not anti-cheat records.

Report a suspected security issue privately to the contact listed on the maintainer's GitHub profile. Include reproduction steps and a minimal example without credentials or personal information. Do not post sensitive files in a public issue.
