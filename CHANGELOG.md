# Changelog

## 1.0.0 — 2026-11-25

- Independent browser implementation of deterministic lane judgments, chords, holds and replay.
- Original synthesized pulse with pauseable audio clock and explicit calibration limits.
- Validated chart editor/import/export, bounded local run history and evidence export.
- Engine tests, static build and architecture/study documentation.

Browser acceptance and public hosting are tracked separately in the verification record; this release entry is not a claim that those checks passed.
